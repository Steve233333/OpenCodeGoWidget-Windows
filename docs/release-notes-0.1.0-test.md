## 这一版有什么

- 托盘常驻：左键点图标开面板，右键菜单（打开主面板 / 设置… / 退出）
- 主面板：按日按模型堆叠花费图、模型图例、三档额度、Go 全模型配额表、刷新按钮
- 设置面板：密钥管理、workspace 凭据、HAR 导入、开机自动启动、Codex 一键配置（界面）
- 关闭窗口收进托盘，不退出进程（与 macOS 版一致）

## 还没接

数据引擎（配额抓取、费用统计、模型自动发现）、Codex 一键配置的实际写入、浏览器登录自动获取 Key。**界面上现在显示的都是演示数据。**

## 已知情况

- 自带 .NET 运行时，目标机器不需要安装任何东西
- 首次启动需要自解压，会慢几秒
- exe 未签名，SmartScreen 会提示，点「仍要运行」即可
- 界面走系统 WebView2：Win11 预装；Win10 若缺失会弹提示框，需另装 WebView2 Runtime
